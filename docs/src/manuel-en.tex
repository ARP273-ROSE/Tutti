\section{What Tutti does}

Tutti does three things, without going through a website:
\begin{itemize}
\item it \textbf{merges} several files into one PDF, in the order you choose, with \textbf{one bookmark
      per part} — designed for sheet music: full score and separate parts;
\item it \textbf{converts to PDF} images (photos, scans) and Word, Excel and PowerPoint documents;
\item it \textbf{splits} a PDF into one file per page, or by page ranges.
\end{itemize}
Your documents stay on your computer: nothing is sent over the Internet.

\begin{securitebox}
\begin{itemize}
\item The original files are \textbf{never modified}: Tutti reads them and only writes the new PDF.
\item Pages are copied \textbf{as they are}, with no loss of quality and no “re-printing”.
\item Tutti refuses to write over one of the files being merged.
\item A power cut during the merge never leaves a half-written PDF behind.
\end{itemize}
\end{securitebox}

\section{Installing Tutti}

Download the latest version from the project's \textbf{Releases} page, picking the file for your
system:

\begin{center}
\renewcommand{\arraystretch}{1.3}
\begin{tabular}{>{\bfseries}l l}
\toprule
Windows & \fichier{Tutti-Setup-X.Y.Z.exe} \\
macOS (Apple M1, M2… chips) & \fichier{Tutti-X.Y.Z-macos-arm64.dmg} \\
macOS (Intel processor) & \fichier{Tutti-X.Y.Z-macos-x86\_64.dmg} \\
Linux & \fichier{Tutti-X.Y.Z-linux-x86\_64.tar.gz} (or \fichier{-arm64}) \\
\bottomrule
\end{tabular}
\end{center}

\textbf{No administrator password is needed}: Tutti installs into your own user profile.

\subsection*{Windows}
Run \fichier{Tutti-Setup-X.Y.Z.exe}. On the very first launch Windows may show “Windows protected
your PC”, because the installer is not signed: click \menu{More info}, then \menu{Run anyway}.
This warning appears only once.

\subsection*{macOS}
Open the \fichier{.dmg} file and drag Tutti into \menu{Applications}. On the first launch macOS
refuses to open an unsigned application: \textbf{right-click} Tutti, choose \menu{Open}, and confirm.

\subsection*{Linux}
Unpack the archive and run \fichier{installer.sh}. Tutti installs into
\fichier{\textasciitilde/.local/share} and appears in the applications menu.

\section{First launch}

Tutti opens in your system's language, French or English. The \menu{Language} menu lets you
force either one.

You are asked once whether to \textbf{send a report automatically if Tutti runs into a problem}.
The report contains the program and system versions and the error; your file names and user name
are hidden. You can change your mind at any time in the \menu{Help} menu.

\section{Merging PDF files, step by step}

\subsection{Adding the files}
\begin{itemize}
\item \textbf{Drag} the PDF files from Explorer (or the Finder) into the large list;
\item or drag \textbf{a whole folder}: every PDF it contains is added, sorted by name;
\item or use \menu{Add files…} \ (\touche{Ctrl}+\touche{O}) and \menu{Add a folder…}.
\end{itemize}
Each file shows its page count and size. A file already in the list is not added twice.

\subsection{Putting them in order}
The order of the list is the order of the merged PDF.
\begin{itemize}
\item \textbf{Drag} a file up or down inside the list;
\item or select it and use \menu{▲ Move up} / \menu{▼ Move down}
      (\touche{Alt}+\touche{↑} / \touche{Alt}+\touche{↓});
\item or click \menu{Sort by name}. The order is “natural”: \fichier{2 Flute} comes before
      \fichier{10 Violin}, as you would expect.
\end{itemize}
\menu{Remove} \ (\touche{Del}) takes the selected files out of the list; \menu{Clear all} empties
it. \textbf{No file is deleted from the disk.}

\capture[0.82]{../capture_triee-en.png}

\subsection{Checking the output file name}
Tutti suggests a name based on what the file names have in common:
\fichier{Symphony No. 5 - 01 Full score}, \fichier{Symphony No. 5 - 02 Flute}… give
\fichier{Symphony No. 5 - complete.pdf}, in the folder of the first file. You can edit it
directly, or pick another location with \menu{Browse…}.

\subsection{Merging}
Click \menu{Merge}. A bar shows the progress; the button turns into \menu{Cancel} while working.
When done, the PDF opens (option \menu{Open the PDF when done}).

\astuce{If the output file already exists, Tutti asks whether to replace it. If it is open in a
PDF reader, close it first: Windows does not allow replacing an open file.}

\section{Options}

\begin{description}[style=nextline,leftmargin=5mm,font=\sffamily\bfseries\color{bordeaux}]
\item[One bookmark per file]
The merged PDF contains one bookmark per original file (“02 Flute”, “10 Violin I”…), shown in the
side panel of your PDF reader. The bookmark is the file name without the part common to all.
\item[Start each part on a right-hand page]
For double-sided printing: when a part ends on a right-hand page, a blank page is inserted so that
the next part also starts on a right-hand page.
\item[Layout: booklet]
For a \textbf{booklet folded and stapled in the middle} (a concert programme, for example). The
booklet is made from \textbf{everything in the list}, in list order: one multi-page file, or several
one-page files (page 1, page 2…), or a mix. Blank pages are added up to a multiple of 4; they go at the
end of the booklet. Two choices:
\begin{itemize}
\item \textbf{A5 booklet ready to print}: two pages reduced to A5, side by side on each side of a
      landscape A4 sheet. Print on A4, landscape, \textbf{actual size (100\%)},
      \textbf{double-sided, flip on the short edge}.
\item \textbf{Booklet order only}: pages keep their size and are simply put in booklet order
      (8, 1, 2, 7, 6, 3, 4, 5 for 8 pages). When printing, choose \textbf{2 pages per sheet},
      landscape, double-sided short edge.
\end{itemize}
Then fold the stack in the middle, nest the sheets and staple along the fold.
\item[Open the PDF when done]
Opens the result in your usual PDF reader. When unchecked, Tutti offers to open the PDF or its folder.
\end{description}

\section{When a file causes trouble}

A damaged or password-protected file is shown \textcolor{bordeaux}{in red} in the list, with the
reason, \textbf{before} merging. The \menu{Merge} button stays greyed out while it is there: select
it and click \menu{Remove}.

\section{Converting images and documents to PDF}

In the \menu{Merge and convert} tab, the list also accepts:
\begin{center}
\renewcommand{\arraystretch}{1.3}
\begin{tabularx}{\linewidth}{>{\bfseries}l X}
\toprule
Images & JPEG, PNG, TIFF (including multi-page), BMP, GIF, WebP \\
Word & \fichier{.doc}, \fichier{.docx}, \fichier{.odt}, \fichier{.rtf} \\
Excel & \fichier{.xls}, \fichier{.xlsx}, \fichier{.ods} \\
PowerPoint & \fichier{.ppt}, \fichier{.pptx}, \fichier{.odp} \\
\bottomrule
\end{tabularx}
\end{center}

Each file is converted as soon as it enters the list; it shows “(image)” or “(converted document)”
and its page count. You can then order it and merge it with PDF files like any other file.

\textbf{To convert a single file}, drop it alone into the list: Tutti suggests the same name with
the \fichier{.pdf} extension (\fichier{Letter.docx} → \fichier{Letter.pdf}), and \menu{Merge}
produces the PDF.

\begin{itemize}
\item \textbf{Images}: one image per page, on A4 in the image's orientation, without distortion.
      A JPEG photo is inserted as is: no loss of quality.
\item \textbf{Word, Excel, PowerPoint}: the layout is done by \textbf{Microsoft Office} when it is
      installed (Windows), otherwise by \textbf{LibreOffice} (free, \fichier{libreoffice.org}), required
      on Mac and Linux. It works invisibly, read-only, with macros disabled. If neither is installed,
      the file is shown in red.
\end{itemize}

\section{Splitting a PDF}

\menu{Split} tab:
\begin{enumerate}
\item drop the file(s) to split into the list: PDF files, but also Word, Excel, PowerPoint
      documents or images (converted automatically, as in the other tab);
\item choose \menu{One page per file}, or \menu{By page ranges}, typing the ranges separated by
      commas: \fichier{1-8, 9-16, 17-} (“\fichier{17-}” means “from page 17 to the end”);
\item choose where to save the files: by default, a \fichier{<name> - pages} folder is created
      next to each PDF;
\item click \menu{Split}.
\end{enumerate}
The files are named \fichier{Score - page 01.pdf}, \fichier{Score - page 02.pdf}… or
\fichier{Score - pages 01-08.pdf}: the leading zeros keep them in order in Explorer.
The original PDF is not modified. If files with the same name already exist, Tutti asks before
replacing them.

\capture[0.82]{../capture_decoupe-en.png}

\subsection*{Combining the functions}
\begin{itemize}
\item \textbf{A 6-page Word document into 6 one-page PDF files}: drop the \fichier{.docx} into the
      \menu{Split} tab and choose \menu{One page per file}.
\item \textbf{Photos and PDF files in one document}: drop them together into \menu{Merge and convert},
      put them in order, merge.
\item \textbf{An Excel sheet to PDF}: drop it alone into \menu{Merge and convert}.
\item \textbf{Pages 3 to 5 of a presentation}: drop the \fichier{.pptx} into \menu{Split}, ranges \fichier{3-5}.
\end{itemize}

\section{Updates}

At startup Tutti quietly checks for a new version. If there is one, it offers to install it: it
downloads it, installs it and restarts. Nothing has to be downloaded by hand. You can also check
yourself: \menu{Help} → \menu{Check for updates}.

\section{Reporting a problem}

\menu{Help} → \menu{Report a problem…}: describe what happened, then \menu{Send}. Without an
Internet connection, the report is saved to a file whose location Tutti shows you.

\section{Privacy}

\begin{itemize}
\item Tutti only goes online to check for updates and, with your consent, to send error reports.
\item None of your files is ever sent. In reports, file names and the user name are hidden.
\end{itemize}
